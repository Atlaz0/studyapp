Stuudium Session Token

Your session token is sent to a Cloudflare Worker and never stored server-side. Paste your _stdmss cookie below.

How to find it:

  1. Open jpg.ope.ee and make sure you're logged in.
  2. Press F12 → Storage tab → Cookies.
  3. Find the row named _stdmss.
  4. Double-click the value and copy it.
  5. Paste it below.
